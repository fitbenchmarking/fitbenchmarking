##########################
AI-Assisted Contributions
##########################


AI tools (e.g. GitHub Copilot, Claude, ChatGPT) may be used to assist with
contributions. However, contributors must:

* Understand all submitted code.
* Test any AI-generated changes.
* Be able to explain the implementation during review.
* Take full responsibility for the contribution.

Maintainers may reject submissions that appear to be unreviewed AI-generated
output or where the contributor cannot adequately explain the submitted changes.

Issues marked ``good first issue`` are intended to help human contributors learn
the project and may not be suitable for AI-generated drive-by pull requests.
